## When to use

- Previewing a profile, page or record behind a link without leaving the page.
- Extra context that sighted pointer users can benefit from but nobody needs.

## When not to use

- **Content that must be reachable on touch or by keyboard alone.** Use a [Popover](/docs/components/popover).
- **A one-line label for an icon.** Use a [Tooltip](/docs/components/tooltip).
- **Actions.** Use a [Dropdown Menu](/docs/components/dropdown-menu).

## Usage

```tsx
import {
  HoverCard,
  HoverCardContent,
  HoverCardTrigger,
} from "@/components/ui/hover-card"

<HoverCard>
  <HoverCardTrigger asChild>
    <a href="/people/maya">@mayachen</a>
  </HoverCardTrigger>
  <HoverCardContent>Interaction designer based in Lisbon.</HoverCardContent>
</HoverCard>
```

## API Reference

### HoverCard

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | | Controlled open state. |
| `defaultOpen` | `boolean` | `false` | Initial open state when uncontrolled. |
| `onOpenChange` | `(open: boolean) => void` | | Called when the card opens or closes. |
| `openDelay` | `number` | `500` | Milliseconds of hover before the card opens. |
| `closeDelay` | `number` | `250` | Milliseconds after leaving before the card closes. |

### HoverCardContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` | Preferred side of the trigger. |
| `align` | `"start" \| "center" \| "end"` | `"center"` | Alignment against the trigger. |
| `sideOffset` | `number` | `6` | Distance from the trigger in pixels. |

## Keyboard

| Key | Action |
| --- | --- |
| `Tab` | Focusing the trigger opens the card after `openDelay`. |
| `Escape` | Closes the card. |

## Accessibility

Built on Radix Hover Card. The card is a visual enhancement and is ignored by screen readers. Keep the trigger meaningful on its own, usually a real link, and never put the only copy of important information in the card.

## Motion

The card scales up from the trigger's side with the **smooth** spring, a touch softer than menus because it opens on intent rather than a click. It exits with the same spring, so moving the pointer back before it closes picks up where it left off. The delays default to 500ms open and 250ms close, shorter than Radix's 700ms so it feels responsive without firing on a passing cursor. With reduced motion it appears instantly.

## Notes for AI

- Use `HoverCardTrigger asChild` with an `<a>` so the trigger stays a real link.
- Don't put buttons or forms in a hover card. Use a popover for interactive content.
