## When to use

- Independent on/off choices inside a form, such as agreeing to terms.
- Picking several items from a list, with an indeterminate parent for "select all".

## When not to use

- **A setting that applies immediately.** Use a [Switch](/docs/components/switch).
- **One choice from a set.** Use a [Radio Group](/docs/components/radio-group).
- **Toolbar on/off buttons.** Use a [Toggle](/docs/components/toggle).

## API Reference

### Checkbox

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `checked` | `boolean \| "indeterminate"` | | Controlled state. |
| `defaultChecked` | `boolean \| "indeterminate"` | `false` | Initial state when uncontrolled. |
| `onCheckedChange` | `(checked: boolean \| "indeterminate") => void` | | Called when the state changes. |
| `disabled` | `boolean` | `false` | Blocks interaction. |
| `required` | `boolean` | `false` | Marks the field as required in a form. |
| `name` | `string` | | Field name for form submission. |
| `value` | `string` | `"on"` | Value submitted with the form when checked. |

## Keyboard

| Key | Action |
| --- | --- |
| `Space` | Toggles the checkbox. An indeterminate checkbox becomes checked. |

## Accessibility

Built on Radix Checkbox, which renders a `button` with `role="checkbox"` and sets `aria-checked` to `true`, `false` or `"mixed"`. Inside a form it renders a hidden native input so the value submits. The check mark SVG is `aria-hidden`.

## Motion

The check path draws in with `pathLength` on the **snappy** spring and retracts the same way on uncheck. Indeterminate swaps the check for a dash that draws in, so moving between all three states is continuous. The box gives a small press scale. All of it is instant with reduced motion.

## Notes for AI

- Clicking an indeterminate checkbox makes it `true`. Derive the parent state from the children, do not store it separately.
- `onCheckedChange` can receive `"indeterminate"`. Compare with `checked === true` rather than treating it as a boolean.
- Put the [Label](/docs/components/label) after the checkbox as a sibling so `peer-disabled` styling works.
