## When to use

- Choosing exactly one option from a short list, two to five items.
- Choices people should compare side by side, such as plans or shipping speeds.

## When not to use

- **Long lists of options.** Use a [Select](/docs/components/select).
- **Several choices at once.** Use a [Checkbox](/docs/components/checkbox) per option.
- **Compact segmented choices in a toolbar.** Use a [Toggle Group](/docs/components/toggle-group).

## Usage

```tsx
import { Label } from "@/components/ui/label"
import { RadioGroup, RadioGroupItem } from "@/components/ui/radio-group"

<RadioGroup defaultValue="comfortable">
  <div className="flex items-center gap-3">
    <RadioGroupItem value="default" id="r1" />
    <Label htmlFor="r1">Default</Label>
  </div>
  <div className="flex items-center gap-3">
    <RadioGroupItem value="comfortable" id="r2" />
    <Label htmlFor="r2">Comfortable</Label>
  </div>
</RadioGroup>
```

## API Reference

### RadioGroup

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | | Controlled selected value. |
| `defaultValue` | `string` | | Initial value when uncontrolled. |
| `onValueChange` | `(value: string) => void` | | Called when the selection changes. |
| `orientation` | `"horizontal" \| "vertical"` | | Limits arrow keys to one axis. |
| `loop` | `boolean` | `true` | Wraps arrow key navigation at the ends. |
| `disabled` | `boolean` | `false` | Disables every item. |
| `name` | `string` | | Field name for form submission. |

### RadioGroupItem

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | | The value this item selects. Required. |
| `disabled` | `boolean` | `false` | Skips the item and blocks interaction. |

## Keyboard

| Key | Action |
| --- | --- |
| `Tab` | Moves focus into the group, to the checked item or the first item. |
| `ArrowDown` / `ArrowRight` | Moves focus to the next item and checks it. |
| `ArrowUp` / `ArrowLeft` | Moves focus to the previous item and checks it. |
| `Space` | Checks the focused item if it is not checked. |

## Accessibility

Built on Radix Radio Group, which provides `radiogroup` and `radio` roles, `aria-checked` and roving focus. Give the group a name with `aria-label` or `aria-labelledby`, and give each item a [Label](/docs/components/label).

## Motion

The inner dot scales in with the **snappy** spring on the selected item while the previous one scales out, so switching reads as one movement. Instant with reduced motion.

## Notes for AI

- Every `RadioGroupItem` needs a unique `value` and an `id` that its `Label` points to.
- Use `orientation="horizontal"` when laying items out in a row so the arrow keys match the layout.
