## When to use

- In a chat, while the other person or the model is composing a reply.

## When not to use

- **Thinking with a label.** Use [Shimmer Text](/docs/components/shimmer-text) when you can say what is happening.
- **Page or data loading.** Use a skeleton.

## Usage

```tsx

<TypingIndicator />
```

## API Reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `label` | `string` | `"Assistant is typing"` | Accessible label announced to screen readers. |

## Accessibility

Renders `role="status"` with an `aria-label`, so its appearance is announced without reading out the dots.

## Motion

Each dot lifts 4px and brightens, offset from the one before it, so the wave reads left to right. With reduced motion, the dots are static.

## Notes for AI

- Inherits `currentColor`. Set the color with a text class.
- Remove it the moment text starts streaming, rather than showing both.
