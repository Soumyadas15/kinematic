## When to use

- Segmented controls with one active option, such as alignment or a date range.
- A row of formatting toggles that can be on together, using `type="multiple"`.

## When not to use

- **Switching between panels of content.** Use [Tabs](/docs/components/tabs).
- **Form choices with longer labels.** Use a [Radio Group](/docs/components/radio-group).
- **A single on/off control.** Use a [Toggle](/docs/components/toggle).

## Usage

```tsx
import { ToggleGroup, ToggleGroupItem } from "@/components/ui/toggle-group"

<ToggleGroup type="single" defaultValue="center" variant="outline">
  <ToggleGroupItem value="left" aria-label="Align left">
    <AlignLeft />
  </ToggleGroupItem>
  <ToggleGroupItem value="center" aria-label="Align center">
    <AlignCenter />
  </ToggleGroupItem>
  <ToggleGroupItem value="right" aria-label="Align right">
    <AlignRight />
  </ToggleGroupItem>
</ToggleGroup>
```

## API Reference

### ToggleGroup

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `type` | `"single" \| "multiple"` | | Whether one or many items can be pressed. Required. |
| `value` | `string \| string[]` | | Controlled value. A string for `single`, an array for `multiple`. |
| `defaultValue` | `string \| string[]` | | Initial value when uncontrolled. |
| `onValueChange` | `(value: string \| string[]) => void` | | Called when the pressed items change. |
| `variant` | `"default" \| "outline"` | `"default"` | `outline` draws a bordered track around the items. |
| `size` | `"default" \| "sm" \| "lg"` | `"default"` | Size applied to every item. |
| `rovingFocus` | `boolean` | `true` | Arrow keys move focus between items. |
| `loop` | `boolean` | `true` | Wraps arrow key navigation at the ends. |
| `orientation` | `"horizontal" \| "vertical"` | | Limits arrow keys to one axis. |
| `disabled` | `boolean` | `false` | Disables every item. |

### ToggleGroupItem

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | | The value this item represents. Required. |
| `disabled` | `boolean` | `false` | Blocks interaction. |

## Keyboard

| Key | Action |
| --- | --- |
| `Tab` | Moves focus into the group, to the pressed item or the first item. |
| `ArrowRight` / `ArrowDown` | Moves focus to the next item. |
| `ArrowLeft` / `ArrowUp` | Moves focus to the previous item. |
| `Home` / `End` | Moves focus to the first or last item. |
| `Space` / `Enter` | Toggles the focused item. |

## Accessibility

Built on Radix Toggle Group. In `single` mode items get `role="radio"` and `aria-checked`. In `multiple` mode they are buttons with `aria-pressed`. Name the group with `aria-label`, and give icon-only items their own `aria-label`. The pill and hover highlight are decorative and `aria-hidden`.

## Motion

In `single` mode, the pressed pill is one shared element that glides between items with the **smooth** spring through a Motion `layoutId`. A muted hover highlight glides between items with the **snappy** spring and hides when the pointer leaves. In `multiple` mode each item shows its own pressed background. Items press in slightly like [Toggle](/docs/components/toggle). All of it is instant with reduced motion.

## Notes for AI

- In `single` mode, Radix lets people un-press the active item, which sets the value to `""`. If a value is always required, control it and ignore empty values in `onValueChange`.
- Set `variant` and `size` on the `ToggleGroup`, not on each item. Items read them from the group.
