## When to use

- A command palette opened with `⌘K` for jumping to pages and running actions.
- Searchable lists of options where filtering beats scrolling.

## When not to use

- **A handful of actions.** Use a [Dropdown Menu](/docs/components/dropdown-menu).
- **Choosing a form value from a short list.** Use a [Select](/docs/components/select).
- **Primary navigation.** Use a [Navigation Menu](/docs/components/navigation-menu).

## Usage

```tsx
import {
  Command,
  CommandEmpty,
  CommandGroup,
  CommandInput,
  CommandItem,
  CommandList,
} from "@/components/ui/command"

<Command>
  <CommandInput placeholder="Type a command or search..." />
  <CommandList>
    <CommandEmpty>No results found.</CommandEmpty>
    <CommandGroup heading="Suggestions">
      <CommandItem>Calendar</CommandItem>
      <CommandItem>Calculator</CommandItem>
    </CommandGroup>
  </CommandList>
</Command>
```

## API Reference

### Command

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | | Controlled value of the selected item. |
| `onValueChange` | `(value: string) => void` | | Called when the selected item changes. |
| `shouldFilter` | `boolean` | `true` | Set `false` to filter results yourself. |
| `filter` | `(value: string, search: string, keywords?: string[]) => number` | | Custom ranking function. |
| `loop` | `boolean` | `false` | Wraps arrow-key navigation at the ends. |

### CommandDialog

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | | Controlled open state. |
| `onOpenChange` | `(open: boolean) => void` | | Called when the dialog opens or closes. |
| `title` | `string` | `"Command Palette"` | Visually hidden dialog title. |
| `description` | `string` | `"Search for a command to run..."` | Visually hidden dialog description. |
| `showCloseButton` | `boolean` | `false` | Renders the dialog close button. |

### CommandItem

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | text content | Value used for filtering and selection. |
| `keywords` | `string[]` | | Extra search terms. |
| `onSelect` | `(value: string) => void` | | Called on click or `Enter`. |
| `disabled` | `boolean` | `false` | Skips the item during navigation. |

Also exported: `CommandInput`, `CommandList`, `CommandEmpty`, `CommandGroup`, `CommandSeparator` and `CommandShortcut`.

## Keyboard

| Key | Action |
| --- | --- |
| `ArrowDown` / `ArrowUp` | Moves to the next or previous item. |
| `Ctrl+N` / `Ctrl+J`, `Ctrl+P` / `Ctrl+K` | Same as the arrow keys. |
| `Alt+ArrowDown` / `Alt+ArrowUp` | Jumps to the next or previous group. |
| `Home` / `End`, `⌘+ArrowUp` / `⌘+ArrowDown` | Moves to the first or last item. |
| `Enter` | Runs the selected item. |
| `Escape` | Closes `CommandDialog`. |

## Accessibility

cmdk renders the input as a `combobox` that controls a `listbox` of `option` items, and keeps `aria-activedescendant` on the selected item, so focus stays in the input while screen readers follow the selection. The gliding highlight is `aria-hidden` and always sits on the item cmdk marks `aria-selected`. `CommandDialog` adds a visually hidden title and description.

## Motion

The highlight glides to the selected item on the **snappy** spring, whether selection moved by arrow key or hover. As results filter, the list height springs to fit on the **smooth** spring instead of snapping. `CommandDialog` opens with the [Dialog](/docs/components/dialog) gentle spring and is anchored near the top, so a resizing list grows downward. All of it is instant with reduced motion.

## Notes for AI

- Don't style the selected item with `data-[selected=true]:bg-*`. The gliding highlight already draws it.
- Give items an explicit `value` when their text isn't unique or contains changing content.
- `CommandDialog` has no open shortcut built in. Add a `⌘K` keydown listener yourself.
