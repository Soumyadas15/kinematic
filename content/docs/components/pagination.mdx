## When to use

- Tables or lists split into numbered pages, where users jump to a specific page.
- Results where a stable URL per page matters.

## When not to use

- **Feeds people scroll through.** Use infinite loading or a "Load more" [Button](/docs/components/button).
- **Switching between a few views.** Use [Tabs](/docs/components/tabs).
- **Very small sets** that fit on one screen.

## Usage

```tsx
import {
  Pagination,
  PaginationContent,
  PaginationEllipsis,
  PaginationItem,
  PaginationLink,
  PaginationNext,
  PaginationPrevious,
} from "@/components/ui/pagination"

<Pagination>
  <PaginationContent>
    <PaginationItem>
      <PaginationPrevious href="?page=1" />
    </PaginationItem>
    <PaginationItem>
      <PaginationLink href="?page=1">1</PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationLink href="?page=2" isActive>
        2
      </PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationEllipsis />
    </PaginationItem>
    <PaginationItem>
      <PaginationNext href="?page=3" />
    </PaginationItem>
  </PaginationContent>
</Pagination>
```

## API Reference

### PaginationLink

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `isActive` | `boolean` | `false` | Marks the current page. Sets `aria-current="page"` and moves the pill here. |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-sm" \| "icon-lg"` | `"icon"` | Size from `buttonVariants`. |
| `href` | `string` | | Destination of the link. |

`PaginationPrevious` and `PaginationNext` take the same props and render a labelled arrow link.

Also exported: `Pagination`, `PaginationContent`, `PaginationItem` and `PaginationEllipsis`.

## Keyboard

| Key | Action |
| --- | --- |
| `Tab` / `Shift+Tab` | Moves between page links. |
| `Enter` | Follows the focused link. |

## Accessibility

The root is a `nav` labelled "pagination". The current page has `aria-current="page"`, previous and next links have `aria-label`s, and the ellipsis is hidden from assistive tech with a screen reader label for context. The pill is decorative and `aria-hidden`.

## Motion

The current page pill is a shared layout element. When the active page changes it glides to the new number with the **smooth** spring, even if the numbers around it shift. With reduced motion it moves instantly.

## Notes for AI

- Each `<Pagination>` owns its pill. Render one `PaginationLink` with `isActive` at a time, or the pill has two homes.
- The pill only glides when the component stays mounted between pages, such as client state or a shared layout. A full page load just shows it in place.
- Disable previous and next at the ends with `aria-disabled`. They are links, not buttons, so `disabled` does nothing.
