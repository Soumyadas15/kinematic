## When to use

- Small, interactive content tied to one control, such as share settings or a quick filter.
- Content the user opens on purpose and may interact with before closing.

## When not to use

- **A list of actions.** Use a [Dropdown Menu](/docs/components/dropdown-menu).
- **Short, non-interactive hints.** Use a [Tooltip](/docs/components/tooltip).
- **Previewing a link on hover.** Use a [Hover Card](/docs/components/hover-card).
- **Tasks that need full focus.** Use a [Dialog](/docs/components/dialog).

## Usage

```tsx
import {
  Popover,
  PopoverContent,
  PopoverDescription,
  PopoverHeader,
  PopoverTitle,
  PopoverTrigger,
} from "@/components/ui/popover"

<Popover>
  <PopoverTrigger asChild>
    <Button variant="outline">Share</Button>
  </PopoverTrigger>
  <PopoverContent>
    <PopoverHeader>
      <PopoverTitle>Share document</PopoverTitle>
      <PopoverDescription>People with access can edit.</PopoverDescription>
    </PopoverHeader>
  </PopoverContent>
</Popover>
```

## API Reference

### Popover

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | | Controlled open state. |
| `defaultOpen` | `boolean` | `false` | Initial open state when uncontrolled. |
| `onOpenChange` | `(open: boolean) => void` | | Called when the popover opens or closes. |
| `modal` | `boolean` | `false` | Blocks interaction outside the popover while open. |

### PopoverContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` | Preferred side of the trigger. Flips when there is no room. |
| `align` | `"start" \| "center" \| "end"` | `"center"` | Alignment against the trigger. |
| `sideOffset` | `number` | `6` | Distance from the trigger in pixels. |
| `onOpenAutoFocus` | `(event: Event) => void` | | Call `event.preventDefault()` to keep focus on the trigger. |

Also exported: `PopoverAnchor`, `PopoverClose`, `PopoverHeader`, `PopoverTitle` and `PopoverDescription`.

## Keyboard

| Key | Action |
| --- | --- |
| `Enter` / `Space` | Opens or closes the popover from the trigger. |
| `Tab` | Moves focus to the next focusable element inside the popover. |
| `Shift` + `Tab` | Moves focus to the previous focusable element. |
| `Escape` | Closes the popover and returns focus to the trigger. |

## Accessibility

Built on Radix Popover. The trigger gets `aria-expanded`, `aria-controls` and `aria-haspopup="dialog"`, and the content has `role="dialog"`. Focus moves into the popover on open and returns to the trigger on close. Give the content a visible title so its purpose is clear.

## Motion

The panel covers its trigger and grows out of it. It's laid out at full size from the start, and a mask animates from the trigger's exact shape and corner radius to the panel's, so text is revealed rather than stretched. A copy of the trigger fades out as the panel's content fades in, and closing runs the same morph in reverse back into the button. If there's no room below, Radix flips the panel above and the morph grows from the trigger's new corner. The shape uses Kinematic's **morphIn** and **morphOut** eases. With reduced motion, it opens and closes instantly.

## Notes for AI

- Use `PopoverTrigger asChild` with a [Button](/docs/components/button) instead of nesting a button inside the trigger.
- Do not add `animate-in` or `data-[state=open]` animation classes. Motion owns enter and exit.
- Set width on `PopoverContent` with `className`. The default is `w-72`.
