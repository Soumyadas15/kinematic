## When to use

- Top-level site navigation with a few sections that each hold several links.
- Marketing headers where a section needs a short description per link.

## When not to use

- **Actions on the current page.** Use a [Dropdown Menu](/docs/components/dropdown-menu).
- **Switching views inside one page.** Use [Tabs](/docs/components/tabs).
- **Showing where the user is in a hierarchy.** Use a [Breadcrumb](/docs/components/breadcrumb).
- **Long lists of pages.** Use a [Command](/docs/components/command) palette.

## Usage

```tsx
import {
  NavigationMenu,
  NavigationMenuContent,
  NavigationMenuItem,
  NavigationMenuLink,
  NavigationMenuList,
  NavigationMenuTrigger,
  navigationMenuTriggerStyle,
} from "@/components/ui/navigation-menu"

<NavigationMenu>
  <NavigationMenuList>
    <NavigationMenuItem>
      <NavigationMenuTrigger>Product</NavigationMenuTrigger>
      <NavigationMenuContent>
        <ul className="grid w-[400px] gap-1">
          <li>
            <NavigationMenuLink href="/deployments">Deployments</NavigationMenuLink>
          </li>
        </ul>
      </NavigationMenuContent>
    </NavigationMenuItem>
    <NavigationMenuItem>
      <NavigationMenuLink href="/pricing" className={navigationMenuTriggerStyle()}>
        Pricing
      </NavigationMenuLink>
    </NavigationMenuItem>
  </NavigationMenuList>
</NavigationMenu>
```

## API Reference

### NavigationMenu

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | | Controlled value of the open item. `""` means closed. |
| `defaultValue` | `string` | `""` | Initial open item when uncontrolled. |
| `onValueChange` | `(value: string) => void` | | Called when an item opens or the menu closes. |
| `viewport` | `boolean` | `true` | Render content inside one shared, resizing viewport. Set `false` to drop each panel under its own trigger. |
| `delayDuration` | `number` | `200` | Hover delay before the first panel opens. |
| `skipDelayDuration` | `number` | `300` | Window in which moving to another trigger opens it without the delay. |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Layout direction, used for keyboard navigation. |

### NavigationMenuItem

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | generated | Identifies the item for controlled use. |

### NavigationMenuLink

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `active` | `boolean` | `false` | Marks the current page. Sets `aria-current="page"` and parks the highlight on it. |
| `onSelect` | `(event: Event) => void` | | Called when the link is chosen. Prevent default to keep the menu open. |
| `asChild` | `boolean` | `false` | Render your router's link instead of an `<a>`. |

### navigationMenuTriggerStyle

A `cva` function returning the trigger classes. Apply it to a top-level `NavigationMenuLink` so it lines up with the triggers.

Also exported: `NavigationMenuTrigger`, `NavigationMenuContent`, `NavigationMenuIndicator` and `NavigationMenuViewport`.

## Keyboard

| Key | Action |
| --- | --- |
| `Enter` / `Space` | Opens or closes the panel of the focused trigger. |
| `ArrowDown` | Moves focus from an open trigger into its panel. |
| `ArrowLeft` / `ArrowRight` | Moves between top-level triggers and links. |
| `ArrowUp` / `ArrowDown` | Moves between links inside a panel. |
| `Home` / `End` | Moves to the first or last item in the current group. |
| `Tab` | Moves to the next focusable element, through the open panel. |
| `Escape` | Closes the panel and returns focus to its trigger. |

## Accessibility

Built on Radix Navigation Menu. The root is a `nav` landmark, triggers expose `aria-expanded` and `aria-controls`, and the viewport keeps panels in tab order after their trigger. Both highlights are `aria-hidden` and only follow keyboard focus when it is visible.

## Motion

- The viewport opens with the **snappy** spring, scaling up from the top and fading in. It exits the same way.
- When you move between triggers, the viewport width and height spring to the next panel with the **smooth** spring.
- The incoming panel slides in from the side you moved toward, also on **smooth**. The outgoing panel is removed at once, so the motion never fights the resize.
- One highlight glides across the top-level items and rests on the open trigger. Each panel has its own highlight for its links. The trigger chevron turns with **snappy**.
- With reduced motion, everything is instant.

## Notes for AI

- Put content inside `NavigationMenuContent` with an explicit width (for example `w-[400px]`). The viewport measures it, so content without a width collapses.
- Use `NavigationMenuLink asChild` around a framework link (`next/link`), never a bare `<a>` inside `NavigationMenuLink`.
- Top-level links need `className={navigationMenuTriggerStyle()}` to match the triggers and join the highlight.
