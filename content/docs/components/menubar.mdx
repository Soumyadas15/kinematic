## When to use

- App-level commands in desktop-like tools, such as editors and dashboards.
- Many related commands grouped under a few well-known headings like File, Edit and View.

## When not to use

- **Site navigation.** Use a [Navigation Menu](/docs/components/navigation-menu).
- **A handful of actions on one object.** Use a [Dropdown Menu](/docs/components/dropdown-menu).
- **Commands people search for by name.** Use a [Command](/docs/components/command) palette.

## Usage

```tsx
import {
  Menubar,
  MenubarContent,
  MenubarItem,
  MenubarMenu,
  MenubarShortcut,
  MenubarTrigger,
} from "@/components/ui/menubar"

<Menubar>
  <MenubarMenu>
    <MenubarTrigger>File</MenubarTrigger>
    <MenubarContent>
      <MenubarItem>
        New tab <MenubarShortcut>⌘T</MenubarShortcut>
      </MenubarItem>
      <MenubarItem>Print…</MenubarItem>
    </MenubarContent>
  </MenubarMenu>
</Menubar>
```

## API Reference

### Menubar

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | | Controlled value of the open menu. `""` means none. |
| `defaultValue` | `string` | `""` | Initially open menu when uncontrolled. |
| `onValueChange` | `(value: string) => void` | | Called when a menu opens or all menus close. |
| `loop` | `boolean` | `true` | Wraps keyboard focus from the last trigger to the first. |

### MenubarMenu

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | auto | Identifier used by the menubar `value`. |

### MenubarContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `align` | `"start" \| "center" \| "end"` | `"start"` | Alignment against the trigger. |
| `alignOffset` | `number` | `-4` | Offset along the alignment axis. |
| `sideOffset` | `number` | `8` | Distance from the trigger in pixels. |

### MenubarItem

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "destructive"` | `"default"` | Visual style. |
| `inset` | `boolean` | `false` | Indents the item to line up with checkbox and radio items. |
| `onSelect` | `(event: Event) => void` | | Called when the item is chosen. |
| `disabled` | `boolean` | `false` | Skips the item during navigation. |

Checkbox items, radio groups and sub-menus take the same props as in [Context Menu](/docs/components/context-menu).

Also exported: `MenubarCheckboxItem`, `MenubarRadioGroup`, `MenubarRadioItem`, `MenubarSub`, `MenubarSubTrigger`, `MenubarSubContent`, `MenubarLabel`, `MenubarSeparator`, `MenubarShortcut`, `MenubarGroup` and `MenubarPortal`.

## Keyboard

| Key | Action |
| --- | --- |
| `ArrowLeft` / `ArrowRight` | Moves between triggers. With a menu open, opens the neighbouring menu. |
| `Enter` / `Space` / `ArrowDown` | Opens the focused trigger's menu. |
| `ArrowUp` / `ArrowDown` | Moves between items in an open menu. |
| `ArrowRight` / `ArrowLeft` | Opens or closes a sub-menu. |
| `Home` / `End` | Moves to the first or last item. |
| `Escape` | Closes the menu and returns focus to its trigger. |
| Letters | Jumps to the next item starting with that letter. |

## Accessibility

Built on Radix Menubar. The bar has `role="menubar"` with roving focus between triggers, and each menu uses `menu`, `menuitem`, `menuitemcheckbox` and `menuitemradio` roles. The trigger highlight and check indicators are `aria-hidden`; open and checked states are exposed with `aria-expanded` and `aria-checked`.

## Motion

The trigger highlight slides between triggers with the **snappy** spring as you hover or move with the keyboard, and stays on the open menu's trigger while you work inside it. When every menu closes and the pointer is elsewhere, it fades out. Each menu scales up from its trigger with the same spring, and items share a gliding highlight just like the [Dropdown Menu](/docs/components/dropdown-menu). Check marks and radio dots scale in when toggled. With reduced motion all of it is instant.

## Notes for AI

- Every `MenubarTrigger` and `MenubarContent` pair must sit inside its own `MenubarMenu`.
- Pass `value` to `MenubarRadioGroup` and `checked` to `MenubarCheckboxItem`. Both are controlled only.
- Keep top-level triggers to short single words. Long labels break the desktop menu pattern.
