## When to use

- A setting that takes effect immediately, such as notifications on or off.
- A single binary choice with a clear label.

## When not to use

- **Choices that apply on submit.** Use a checkbox inside the form.
- **Picking one of several options.** Use a radio group or [Tabs](/docs/components/tabs).

<AddCommand slug="switch" />

## Usage

```tsx
import { Switch } from "@/components/ui/switch"

<label>
  <Switch defaultChecked />
  Airplane mode
</label>
```

## API Reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `checked` | `boolean` | | Controlled state. |
| `defaultChecked` | `boolean` | `false` | Initial state when uncontrolled. |
| `onCheckedChange` | `(checked: boolean) => void` | | Called when the state changes. |
| `disabled` | `boolean` | `false` | Prevents interaction. |

## Keyboard

| Key | Action |
| --- | --- |
| `Tab` | Moves focus to the switch. |
| `Space` / `Enter` | Toggles the switch. |

## Accessibility

Built on Radix Switch: it renders `role="switch"` with `aria-checked`. Wrap it in a `<label>`, or pass `aria-label` when there is no visible text.

## Motion

While pressed, the thumb stretches by 4px towards where it will travel. On release it springs across with **smooth**. With reduced motion it moves instantly.

## Notes for AI

- Always pair a switch with a visible label or `aria-label`.
- Don't use a switch for form fields that only save on submit.
