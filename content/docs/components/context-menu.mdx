## When to use

- Shortcuts to actions on an object, such as a file, row or canvas element.
- Power-user paths that duplicate actions already available elsewhere.

## When not to use

- **The only way to reach an action.** Context menus are hidden. Also expose the action with a [Button](/docs/components/button) or [Dropdown Menu](/docs/components/dropdown-menu).
- **App-level commands.** Use a [Menubar](/docs/components/menubar) or [Command](/docs/components/command).

## Usage

```tsx
import {
  ContextMenu,
  ContextMenuContent,
  ContextMenuItem,
  ContextMenuTrigger,
} from "@/components/ui/context-menu"

<ContextMenu>
  <ContextMenuTrigger className="rounded-xl border border-dashed p-12">
    Right-click here
  </ContextMenuTrigger>
  <ContextMenuContent>
    <ContextMenuItem>Rename</ContextMenuItem>
    <ContextMenuItem>Duplicate</ContextMenuItem>
    <ContextMenuItem variant="destructive">Delete</ContextMenuItem>
  </ContextMenuContent>
</ContextMenu>
```

## API Reference

### ContextMenu

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `onOpenChange` | `(open: boolean) => void` | | Called when the menu opens or closes. |
| `modal` | `boolean` | `true` | Blocks interaction outside the menu while open. |

### ContextMenuTrigger

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `disabled` | `boolean` | `false` | Lets the native context menu show instead. |

### ContextMenuItem

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" \| "destructive"` | `"default"` | Visual style. |
| `inset` | `boolean` | `false` | Indents the item to line up with checkbox and radio items. |
| `onSelect` | `(event: Event) => void` | | Called when the item is chosen. Call `event.preventDefault()` to keep the menu open. |
| `disabled` | `boolean` | `false` | Skips the item during navigation. |

### ContextMenuCheckboxItem

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `checked` | `boolean \| "indeterminate"` | `false` | Controlled checked state. |
| `onCheckedChange` | `(checked: boolean) => void` | | Called when the item is toggled. |

### ContextMenuRadioGroup

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | | The selected radio item. |
| `onValueChange` | `(value: string) => void` | | Called when another item is chosen. |

### ContextMenuSub

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | | Controlled open state of the sub-menu. |
| `defaultOpen` | `boolean` | `false` | Initial open state when uncontrolled. |
| `onOpenChange` | `(open: boolean) => void` | | Called when the sub-menu opens or closes. |

Also exported: `ContextMenuRadioItem`, `ContextMenuSubTrigger`, `ContextMenuSubContent`, `ContextMenuLabel` (with `inset`), `ContextMenuSeparator`, `ContextMenuShortcut`, `ContextMenuGroup` and `ContextMenuPortal`.

## Keyboard

| Key | Action |
| --- | --- |
| `Shift` + `F10` / Context menu key | Opens the menu when the trigger is focused (browser dependent). |
| `ArrowUp` / `ArrowDown` | Moves between items. |
| `Home` / `End` | Moves to the first or last item. |
| `ArrowRight` | Opens a sub-menu and focuses its first item. |
| `ArrowLeft` | Closes the sub-menu and returns to its trigger. |
| `Enter` / `Space` | Chooses the focused item or opens a sub-menu. |
| `Escape` | Closes the menu. |
| Letters | Jumps to the next item starting with that letter. |

## Accessibility

Built on Radix Context Menu, which handles `menu`, `menuitem`, `menuitemcheckbox` and `menuitemradio` roles, focus management and typeahead. Long-press opens the menu on touch devices. The gliding highlight and check indicators are `aria-hidden`; checked state is exposed with `aria-checked`.

## Motion

The menu scales up from the pointer position with the **snappy** spring and exits with the same spring. Sub-menus spring from the side of their trigger. One highlight glides between items on hover and keyboard focus, and it rests on a sub-menu's trigger while that sub-menu is open. Check marks and radio dots scale in and out when toggled. All of it is instant with reduced motion.

## Notes for AI

- Radix `ContextMenuCheckboxItem` is controlled only. Always pass `checked` and `onCheckedChange`.
- Pass `value` to `ContextMenuRadioGroup`. The radio dot reads it to know which item is selected.
- Every action in a context menu must also be reachable some other way.
