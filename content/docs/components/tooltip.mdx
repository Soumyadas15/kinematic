## When to use

- Naming icon-only buttons and showing their keyboard shortcuts.
- Short supplementary text that isn't needed to complete a task.

## When not to use

- **Rich or interactive content.** Use a [Popover](/docs/components/popover) or [Hover Card](/docs/components/hover-card).
- **Essential information.** Tooltips are hidden on touch devices. Put it in the layout.
- **Form validation messages.** Show them inline next to the field.

## Usage

```tsx
import {
  Tooltip,
  TooltipContent,
  TooltipProvider,
  TooltipTrigger,
} from "@/components/ui/tooltip"

<TooltipProvider>
  <Tooltip>
    <TooltipTrigger asChild>
      <Button size="icon" variant="ghost" aria-label="Bold">
        <Bold />
      </Button>
    </TooltipTrigger>
    <TooltipContent>Bold</TooltipContent>
  </Tooltip>
</TooltipProvider>
```

## API Reference

### TooltipProvider

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `delayDuration` | `number` | `400` | Milliseconds of hover before the first tooltip opens. |
| `skipDelayDuration` | `number` | `500` | Window after a tooltip closes in which the next one opens instantly. |
| `disableHoverableContent` | `boolean` | `false` | Closes the tooltip as soon as the pointer leaves the trigger. |

### Tooltip

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `open` | `boolean` | | Controlled open state. |
| `defaultOpen` | `boolean` | `false` | Initial open state when uncontrolled. |
| `onOpenChange` | `(open: boolean) => void` | | Called when the tooltip opens or closes. |
| `delayDuration` | `number` | | Overrides the provider delay for this tooltip. |

### TooltipContent

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"top"` | Preferred side of the trigger. |
| `align` | `"start" \| "center" \| "end"` | `"center"` | Alignment against the trigger. |
| `sideOffset` | `number` | `4` | Distance from the trigger in pixels. |

## Keyboard

| Key | Action |
| --- | --- |
| `Tab` | Focusing the trigger opens the tooltip immediately. |
| `Escape` | Closes the tooltip. |

## Accessibility

Built on Radix Tooltip. The content has `role="tooltip"` and the trigger is described by it with `aria-describedby`. Tooltips open on hover and keyboard focus, not on touch. An icon-only trigger still needs its own `aria-label`; the tooltip is a description, not a name.

## Motion

The first tooltip waits 400ms, then scales and fades in from its trigger with the **snappy** spring. Once one has been shown, moving to a neighbouring trigger within 500ms opens the next one instantly, and it only fades in without the scale, so gliding along a toolbar feels like one label following the cursor. Exits use the same spring. With reduced motion tooltips appear instantly.

## Notes for AI

- Wrap a group of tooltips, such as a toolbar, in one `TooltipProvider`. The skip-delay only works between tooltips that share a provider. A `Tooltip` without a provider creates its own.
- Put `TooltipProvider` high in the tree, for example in your root layout, rather than around each tooltip.
- Always give icon-only triggers an `aria-label` as well as a tooltip.
