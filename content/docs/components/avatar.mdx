## When to use

- Representing a person or team in lists, comments, menus and headers.
- Stacking collaborators with `AvatarGroup`.

## When not to use

- **Product or content images.** Use a regular `img`.
- **Decorative icons.** Use an icon directly.

## Installation

<AddCommand slug="avatar" />

## Usage

```tsx
import {
  Avatar,
  AvatarFallback,
  AvatarGroup,
  AvatarImage,
} from "@/components/ui/avatar"

<Avatar>
  <AvatarImage src="/lena.jpg" alt="Lena Ortiz" />
  <AvatarFallback>LO</AvatarFallback>
</Avatar>

<AvatarGroup>
  <Avatar>...</Avatar>
  <Avatar>...</Avatar>
</AvatarGroup>
```

## API Reference

### AvatarImage

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `src` | `string` | | Image URL. |
| `alt` | `string` | | Alternative text. Usually the person's name. |
| `onLoadingStatusChange` | `(status: "idle" \| "loading" \| "loaded" \| "error") => void` | | Called as the image loads. |

### AvatarFallback

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `delayMs` | `number` | | Waits before showing the fallback, to avoid a flash on fast connections. |

### AvatarGroup

Accepts the props of a `div`. Overlaps its avatars and rings each with the background color.

Also exported: `Avatar` and `AvatarGroupCount` for a "+3" overflow chip.

## Accessibility

Built on Radix Avatar. Give `AvatarImage` an `alt` with the person's name. The image only renders once it has loaded, so broken images never show. If the avatar sits next to the name already, use `alt=""` to avoid repetition.

## Motion

When the image loads, it fades in with the **smooth** spring while the fallback fades out on the same spring, so initials crossfade into the photo instead of popping. Instant with reduced motion.

## Notes for AI

- Always include an `AvatarFallback`. It shows while loading and when the image fails.
- Change shape with `className` on both `Avatar` and `AvatarFallback`, such as `rounded-lg`.
- `AvatarImage` and `AvatarFallback` must be inside `Avatar`.
