## When to use

- Pages nested two or more levels deep, where users need a way back up.
- Headers of detail views such as a project's settings page.

## When not to use

- **Top-level site navigation.** Use a [Navigation Menu](/docs/components/navigation-menu).
- **Steps in a flow.** Breadcrumbs show location, not progress. Use [Progress](/docs/components/progress) or a stepper.
- **Flat sites** with only one level. There is nothing to trace back.

## Usage

```tsx
import {
  Breadcrumb,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@/components/ui/breadcrumb"

<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="/">Home</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbLink href="/projects">Projects</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>Settings</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```

## API Reference

### BreadcrumbLink

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `asChild` | `boolean` | `false` | Render your router's link instead of an `<a>`. |
| `href` | `string` | | Destination of the link. |

### BreadcrumbSeparator

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | `<ChevronRight />` | Custom separator icon. |

Also exported: `Breadcrumb`, `BreadcrumbList`, `BreadcrumbItem`, `BreadcrumbPage` and `BreadcrumbEllipsis`.

## Keyboard

| Key | Action |
| --- | --- |
| `Tab` / `Shift+Tab` | Moves between links. The highlight follows visible focus. |
| `Enter` | Follows the focused link. |

## Accessibility

The root is a `nav` labelled "breadcrumb" and the trail is an ordered list. The current page is marked with `aria-current="page"`. Separators and the ellipsis are hidden from assistive tech, and the highlight is `aria-hidden`.

## Motion

Hovering or focusing a link moves a shared highlight to it with the **snappy** spring. The highlight fades out when the pointer leaves the trail. With reduced motion it jumps instead of gliding.

## Notes for AI

- Render the last item as `BreadcrumbPage`, not a link to the current page.
- Put `BreadcrumbSeparator` between items as a sibling of `BreadcrumbItem`, never inside it.
- For collapsed trails, put `BreadcrumbEllipsis` inside a [Dropdown Menu](/docs/components/dropdown-menu) trigger that lists the hidden pages.
