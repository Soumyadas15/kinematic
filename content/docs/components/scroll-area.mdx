## When to use

- Fixed-height panels inside a layout, like a sidebar list, a log or a code block.
- Horizontal rows of cards or images.

## When not to use

- **The whole page.** Let the browser scroll the document.
- **Short content that fits.** Don't add a container that never scrolls.

## Usage

```tsx
import { ScrollArea, ScrollBar } from "@/components/ui/scroll-area"

<ScrollArea className="h-64 w-48 rounded-lg border">
  <div className="p-4">{items}</div>
</ScrollArea>

<ScrollArea className="w-full whitespace-nowrap">
  <div className="flex w-max gap-3">{cards}</div>
  <ScrollBar orientation="horizontal" />
</ScrollArea>
```

## API Reference

### ScrollArea

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `type` | `"hover" \| "scroll" \| "auto" \| "always"` | `"hover"` | When scrollbars show. `hover` uses the Kinematic fade. Other values use Radix behaviour. |
| `scrollHideDelay` | `number` | `600` | Milliseconds the scrollbar stays visible after scrolling stops. |
| `dir` | `"ltr" \| "rtl"` | | Reading direction. |

### ScrollBar

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `orientation` | `"vertical" \| "horizontal"` | `"vertical"` | Axis of the scrollbar. A vertical one is included by default. |

## Keyboard

| Key | Action |
| --- | --- |
| `Tab` | Focuses the viewport. Modern browsers make scrollable regions focusable when they have no focusable children. |
| `ArrowUp` / `ArrowDown` | Scrolls the focused viewport. |
| `PageUp` / `PageDown` / `Space` | Scrolls by one page. |
| `Home` / `End` | Scrolls to the start or end. |

## Accessibility

Built on Radix Scroll Area. Native scrolling is kept, so wheel, touch, keyboard and assistive tech all work as usual. The custom scrollbars are visual only. The viewport shows a focus ring when focused with the keyboard.

## Motion

With the default `hover` type, scrollbars fade in with the **snappy** spring while the pointer is over the area or it is scrolling, and fade out after `scrollHideDelay`. They only appear on axes that actually overflow. With other types, scrollbars fade in when Radix mounts them. Instant with reduced motion.

## Notes for AI

- Give the `ScrollArea` a fixed height or width. Without one it grows with its content and never scrolls.
- Add `<ScrollBar orientation="horizontal" />` for horizontal scrolling, and give the inner content `w-max`.
