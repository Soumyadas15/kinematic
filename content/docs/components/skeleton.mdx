## When to use

- Content with a known layout that takes a moment to load, like a list, a card or a profile.
- Keeping the page from jumping when data arrives.

## When not to use

- **Unknown or long waits.** Use a [Progress](/docs/components/progress) bar or a spinner.
- **Actions in flight.** Show a disabled [Button](/docs/components/button) with a loading label.

```tsx
<div className="flex items-center gap-3">
  <Skeleton className="size-9 rounded-full" />

    <Skeleton className="h-3 w-48" />
  </div>
</div>
```

## API Reference

### Skeleton

Accepts the props of a `div`. Set size and shape with `className`.

## Accessibility

Skeletons have no role and no text. Mark the loading region with `aria-busy="true"` and give it an accessible label, or show visually hidden "Loading" text, so screen reader users know something is coming.

## Motion

A soft highlight sweeps left to right on a CSS loop. It's a loop rather than a state change, so it uses a CSS animation instead of a spring. The keyframes ship inside the component through a hoisted React `<style>` tag, so no global CSS is needed. With reduced motion the shimmer is removed and the block is a flat muted color.

## Notes for AI

- Match the size and shape of the real content, so nothing shifts when it loads.
- Don't add `animate-pulse`. The shimmer is already built in.
