---

kinematic is a shadcn registry. Components install with the shadcn CLI and land in your codebase as plain source, using the same `cn` helper, tokens and Radix primitives you already have. What's different is how they move.

## Principles

<Cards>
  <Card title="Springs, not durations">
    Every transition is a spring tuned by feel. Interrupt one mid-flight and it reverses from where it is, never from where it started.
  </Card>
  <Card title="Motion carries meaning">
    Things move to show where focus went, what changed and where a click will land. Nothing moves just to be seen.
  </Card>
  <Card title="One system">
    Three spring presets and one highlight primitive sit under every component, so the whole library feels like one hand made it.
  </Card>
  <Card title="Yours to own">
    Built on shadcn/ui and Radix. The CLI copies source into your project, and you change whatever you like.
  </Card>
</Cards>
