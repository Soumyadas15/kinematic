## Markdown for every page

Append `.mdx` to any docs URL to get the page as Markdown. The **Copy page** button at the top of each page copies it to your clipboard, or opens it in Claude or ChatGPT.

```txt
/docs/components/tabs.mdx
```

## llms.txt

[`/llms.txt`](/llms.txt) lists every page with a one-line summary and a link to its Markdown, following the [llms.txt](https://llmstxt.org) convention. Point your agent at it and it can find the right page on its own.

## Notes for AI

Each component page ends with a **Notes for AI** section: the rules an agent most often gets wrong, such as which spring preset to use or when to reach for a different component.
